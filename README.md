**Another Quality Ore Set** is a mod where beauty meets power in combat, with four metallic sets that blend into Vanilla Minecraft.

# The Three Sets

This mod adds three new material sets, in increasing power: Easium, Medium, and Hardium.

### Easium

The green-themed Easium set is the lowest of the sets. It is crafted with easium ore, found naturally in the overworld, and has the approximate strength of iron.

### Medium

The orange-red themed Medium set sits in the middle, with the approximate strength of diamond. It is crafted with medium ore, which can be mined only in the nether.

Wearing the whole set gives a fire resistance effect.

### Hardium

The blue-themed Hardium set is the highest of the three tiers. It is crafted with hardium ore, which can only be mined at the end, and hardium.

Wearing the whole set gives water breathing and elytra flight.

# Three Special Tools

Each set doesn’t only come with the standard gear and tools. Introducing: the **paxel, tree axe, and hammer!**

*   Paxel: Acts as a pickaxe, axe, and shovel all in one
*   Tree axe: Cutting one log of a tree will cut the whole tree down
*   Hammer: Breaking a block will also break blocks around it in a radius

# But there’s more…

This mod adds another powerful armor set called the **Telos set.** A meticulous blend between Easium, Medium and Hardium, this set is the epitome of power and elegance. Wearing the full Telos set gives Water Breathing, Elytra Flight, and Infinite Durability, and the sword also has a special projectile attack. The set can be crafted from Telos Scraps.
